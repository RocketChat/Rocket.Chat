Redesigns the user card and opens it on hover instead of click. The card now shows a compact header (avatar, status, name and custom status), an icon-led info list (role tags, local time, bio and a "See member profile" link) and labeled action buttons with an overflow menu. Message author names are underlined on hover, and when a user has more than two roles the message header collapses them into the first role plus a clickable "+ N roles" tag that opens the user card. All information in the card is exposed to assistive technology.
