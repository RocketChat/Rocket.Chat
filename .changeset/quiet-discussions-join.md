Improves discussion navigation in the message list, bringing it in line with threads: discussion messages now show a "Discussion" button (highlighted only when you're a member with unread messages), a join/leave action, a members avatar stack and a unified reply count and last message time. Threads now show a "Thread" button with the thread icon, reply counts are properly pluralized, and "Last message" tooltips follow the user's date and time preferences without seconds.
