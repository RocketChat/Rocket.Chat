Adds the **Dark (Alpha)** theme: a translucency-based dark theme in which the only opaque color is the anchor (`surface-tint`, painted on `<body>`) and every other surface is an alpha veil over it — so re-tinting the anchor re-tints the whole workspace. Also adds the *Layout → Dark (Alpha) theme* admin settings for an optional workspace watermark (image URL + opacity, empty by default).
