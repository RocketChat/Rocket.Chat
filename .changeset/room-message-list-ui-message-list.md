Renders the room's messages with the message list of `@rocket.chat/ui-message-list`: older and newer pages load without moving what is on screen, the list stays at the latest message while content grows or the composer resizes, and a link to a message, the unread banner and "Jump to recent messages" land on the message. Visible difference: "Select all" scrolls to the top of the loaded messages at once instead of smoothly.
