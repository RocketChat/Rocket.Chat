## Rocket.Chat rules

**Always confirm with the human before adding a changeset.**

Every user-visible change needs `yarn changeset` → `<random-name>.md` w/ affected workspaces, bump (`patch`/`minor`/`major`), release-note line.

**Only changesets that bump `'@rocket.chat/meteor'` appear in public release notes** — list it for any user-visible change even if the actual edit is in a sub-package (e.g. `@rocket.chat/ui-client`, `@rocket.chat/i18n`). Still bump every workspace whose published surface changed; `@rocket.chat/meteor` is added on top.
