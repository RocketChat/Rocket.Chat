Opens the user card by hovering a message author's name or avatar, or a user mention, and opens the full user info by clicking them. Lists inside the contextual bar (threads, search, pinned, starred and similar) only open the user info, since the card would cover them. Video calls from the user card or user info no longer require an existing direct message: one is created on demand
