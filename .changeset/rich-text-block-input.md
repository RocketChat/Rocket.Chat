Adds the `rich_text` layout block and the `rich_text_input` element to UiKit. `rich_text` renders structured text (styled text, lists, quotes, code, mentions by id, links, emoji, dates) in messages, modals and contextual bars; `rich_text_input` lets the user type Markdown and reports the value as a `rich_text` block.
