# Architecture Decision Records

This directory holds Architecture Decision Records (ADRs) — short documents capturing a significant
decision, the context that forced it, and its consequences. They are the authoritative record of
"how we do X and why".

- One file per decision, named `NNNN-kebab-title.md` (zero-padded, incrementing).
- Status is one of `Proposed`, `Accepted`, `Superseded by NNNN`, `Deprecated`.
- Keep them short and durable. How-to guides live elsewhere in `docs/`; an ADR links to them.
