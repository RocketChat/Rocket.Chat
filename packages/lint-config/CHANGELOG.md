# @rocket.chat/lint-config

## 0.1.0-rc.0

### Minor Changes

- ([#43037](https://github.com/RocketChat/Rocket.Chat/pull/43037)) Adds an opt-in `spacing-scale` rule, exported from `@rocket.chat/lint-config/rules` as an oxlint JS plugin, that reports literal spacing values that aren't Fuselage spacing tokens

- ([#43010](https://github.com/RocketChat/Rocket.Chat/pull/43010)) Adds `@rocket.chat/lint-config`, Rocket.Chat's shared oxlint config (`@rocket.chat/lint-config/oxlint.json`), replacing `@rocket.chat/eslint-config`.
