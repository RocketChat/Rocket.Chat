# Data Display

Components that show content and status rather than take input.

## People and status

- A user or entity as a picture: [`Avatar`](?path=/docs/data-display-avatar--docs)
- A user's presence: [`StatusBullet`](?path=/docs/data-display-statusbullet--docs)
- The count and type of unread notifications: [`Badge`](?path=/docs/data-display-badge--docs)

## Labels and values

- A short set value, such as a role or a username: [`Tag`](?path=/docs/data-display-tag--docs)
- A selection the user made in an input, which they can remove: [`Chip`](?path=/docs/data-display-chip--docs)
- Text in one of the design system's font scales and colours: [`Text`](?path=/docs/data-display-text--docs)
- Code or a command the user will copy: [`CodeSnippet`](?path=/docs/data-display-codesnippet--docs)
- Records in rows and columns: [`Table`](?path=/docs/data-display-table--docs)

## Icons

- An icon from the Rocket.Chat icon set: [`Icon`](?path=/docs/data-display-icon--docs)
- An icon in a coloured frame, to signal a state: [`FramedIcon`](?path=/docs/data-display-framedicon--docs)
- An arrow that shows a section expands or collapses: [`Chevron`](?path=/docs/data-display-chevron--docs)

## Progress

- Progress or consumption with a known amount: [`ProgressBar`](?path=/docs/data-display-progressbar--docs)
- Loading of unknown length: [`Throbber`](?path=/docs/data-display-throbber--docs), or a
  [`Skeleton`](?path=/docs/layout-skeleton--docs) in the shape of the content that is coming

## Around content

- Complementary information on hover: [`Tooltip`](?path=/docs/data-display-tooltip--docs)
- A floating control in a scrolling feed, such as a jump to new messages: [`Bubble`](?path=/docs/data-display-bubble--docs)
- A line between groups of content: [`Divider`](?path=/docs/data-display-divider--docs)
